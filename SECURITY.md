# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
**Security > Report a vulnerability** on https://github.com/jertech/verdi-ha.
Do not open a public issue.

Include what you found and how to reproduce it, but **never** include tokens,
`verdi_state.json`, HAR files, screenshots of a browser's network tab, Verdi IDs, or
anyone's name. If a report needs such data, say so and we will agree on a safe way.

## Scope

- The Home Assistant integration in `custom_components/verdi`.
- The Verdi Token Grabber app and script in `verdi_token_grabber`.

Problems in Verdi itself are out of scope; report those to its publisher.

## Supported versions

Only the latest release receives fixes.
